## Resumo

Este trabalho consiste na implementação, em Python, de um pequeno conversor de Markdown para HTML.

O conversor suporta os seguintes elementos da sintaxe básica de Markdown:

* Cabeçalhos (`#`, `##` e `###`)
* Negrito (`**texto**`)
* Itálico (`*texto*`)
* Listas numeradas
* Links
* Imagens

## Resolução

[Ver resolução](./markdown_to_html.py)

A implementação utiliza expressões regulares para identificar e converter os diferentes elementos de Markdown para HTML.
